¿Qué es Python?

Es un lenguaje de programación: un conjunto de reglas y palabras que usamos para escribir instrucciones que una computadora puede ejecutar.

UN LENGUAJE AMIGABLE

¿Por qué se lee fácil?

Python busca que el código sea legible. Sus instrucciones suelen parecerse a palabras conocidas y evita algunos símbolos repetitivos.

  • Claro: el código se puede leer de un vistazo.
  • Versátil: sirve para muchos tipos de proyectos.
  • Con comunidad: hay documentación y recursos para aprender.
